# 🎨 Desktop Dark Theme Styling Tokens

## 1. Color Palette Tokens
| Token | Hex Value | Usage |
| :--- | :--- | :--- |
| **`BgDark`** | `#1E1E2E` | Window background |
| **`BgCard`** | `#252538` | Card / Container background |
| **`BgInput`** | `#2E2E44` | TextBox / ComboBox background |
| **`BorderDefault`** | `#3E3E58` | Control borders |
| **`PrimaryAccent`** | `#89B4FA` | Main buttons, active tabs |
| **`SuccessAccent`** | `#A6E3A1` | Approve, Save badges |
| **`DangerAccent`** | `#F38BA8` | Delete, Error indicators |
| **`TextPrimary`** | `#CDD6F4` | Primary label & table text |
| **`TextMuted`** | `#6C7086` | Placeholders & hints |

## 2. DevExpress Dark Theme Sync
- Use `SVG` icons with CSS color mapping.
- Avoid hardcoded system brushes (`SystemColors.Control`).
